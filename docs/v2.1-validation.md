# v2.1 Validation

This document is the release checklist for the `Safer Batch Downloads`
milestone. Automated checks should pass before the unpacked Chrome matrix is
started. Record the Chrome version and results in the final section.

## Automated Evidence

Run from the repository root with Codex's bundled Node runtime:

```powershell
$node = 'C:\Users\ckajs\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin\node.exe'
& $node --check download-utils.js
& $node --check popup-state.js
& $node --check popup.js
& $node --check background.js
& $node --test tests/*.test.js
Get-Content -Raw manifest.json | ConvertFrom-Json | Out-Null
git diff --check
```

The automated suite covers:

- aborting a 200-item queue, active download cancellation, retry suppression,
  late batches, late Chrome ids, duplicate events, and completion/abort races;
- service-worker restoration of active and pending downloads, including an
  indeterminate launch that must not be duplicated;
- starting a fresh batch after an aborted session;
- destination traversal, stable thread folders, Windows reserved names,
  filename source priority, MIME extensions, route-name rejection, stable
  fallbacks, and deterministic duplicate suffixes;
- page-fetch controller cancellation;
- v2.0 progress and download-setting migration;
- selected/filter/ignore behavior, page-scoped saved state, confirmation
  threshold, and the popup DOM/script contract.

## Permission Gate

`manifest.json` must retain the local-first permission set. Version `2.1` must
not add a backend, telemetry, accounts, cloud dependencies, multi-page crawling,
or broad host access. The only host permission remains:

```text
https://i.pximg.net/*
```
